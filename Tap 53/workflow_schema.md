# Workflow schema compatibility

Schema dùng chung đã được chia theo trách nhiệm trong các reference của
`.agents/skills/`. Dùng schema của skill đang thực hiện công việc; trạng thái
kiểm tra điều kiện là `REQUIRED`, `NOT_APPLICABLE` hoặc `SKIPPED_BY_USER`.

File này chỉ giữ đường dẫn tương thích cho artifact cũ.
