# Profile QA

Đối chiếu trực tiếp từng nhân vật với profile gốc:

- khuôn mặt;
- tóc/râu;
- tuổi và tỷ lệ cơ thể;
- trang phục và màu;
- phụ kiện;
- silhouette;
- dấu hiệu phân biệt với nhân vật khác.

Kiểm đầu–cổ–vai–thân–tay và scale đồng nhất. Nhầm identity hoặc sai từ hai dấu
hiệu profile cốt lõi làm toàn shot FAIL. Variant phải so với profile gốc, không
chỉ so với output trước.
