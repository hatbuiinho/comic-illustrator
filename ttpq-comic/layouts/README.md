# Layout

Đặt PDF layout xuất từ InDesign vào đây. Mỗi trang PDF là một spread: trang
trái tiếng Việt, trang phải tiếng Anh. Tên file không dấu, ví dụ
`t53-part-2.pdf`; phần tên (không đuôi) là `<layout-slug>` của thư mục spread.

  cùng phân trang; chữ và ô hình đổi ở nhiều spread). Bản trước xem trong git
  history; layout cũ của các spread đã làm lưu ở `<spread>/layout-prev-2026-10-28/`.
