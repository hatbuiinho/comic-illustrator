# Bối cảnh

Mỗi bối cảnh (địa danh, kiến trúc, nội thất) một thư mục `settings/<slug>/`:

- `ref-vNNN.png` — ảnh ref do người dùng chỉ định (chép vào đây).
- `setting.md` — mô tả bằng chữ theo mẫu
  `.agents/skills/ttpq-comic/references/setting-template.md`.

Chỉ setting có `Trạng thái: APPROVED` được đưa vào prompt.
